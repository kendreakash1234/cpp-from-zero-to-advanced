## 🚀 Learning Philosophy

I am following a structured approach:

**Learn → Understand → Code → Practice → Document → Repeat**

I will not skip fundamentals just because they appear simple.

Strong C++ knowledge requires understanding what happens underneath the code, including:

* Memory
* Object lifetime
* Pointers
* References
* Resource management
* Compilation
* Linking
* Performance
* Concurrency
* Low-level system behavior
